# Saves

Cartridge saves (128 KiB flash + RTC, as written by mGBA) of play-throughs of this ROM.
Load one in an emulator by placing it next to the ROM with the ROM's name and a `.sav`
extension, or use it with `tools/playtest` (see its README).
