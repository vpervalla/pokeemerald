# Walkthrough log

One file per area, in the order the run visits them: `NN_area_name.md` (a town, city, route, cave or other
dungeon), with its screenshots in `img/NN_*.png`. The run is described in `../playthrough_guide.md`; bugs go in
`../playthrough_bugs.md`, each linked from the area where it was found.

Each area file has, in this order:

1. **Arrival:** how and when the player gets there (from where, which badges, party level), and the map and (x,y) of the entrance.
2. **Map notes:** buildings and exits with their coordinates, one-way ledges, blocked paths and what unblocks them.
3. **Story:** short numbered steps of what to do, with the screenshots.
4. **Items:** every item ball, hidden item, gift and purchase worth knowing, with coordinates.
5. **Pokémon:** wild encounters seen (day and night, levels, how they were caught), in-game trades and gifts.
6. **Trainers:** each trainer with their team, levels, and the reward.
7. **Shops:** stock and prices.
8. **Party after:** the party, levels and moves when leaving, plus the money and badges.
9. **Bugs:** links to the bug log, or "none found", and the interactions tested.
10. **Save:** the name of the save made at the end of the area, if any.

Facts come from the run (the build differs from FireRed and Emerald), never from memory of the originals.
